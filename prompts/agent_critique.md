утверждение текстом процитированных фрагментов CONTEXT. Наличие корректного ID
само по себе не доказывает истинность утверждения. Нельзя дополнять внешними знаниями.

"relevant":true,"grounded":true}.
accept разрешён только для релевантного ответа без неподтверждённых фактов и с issues=[].
fix — контекста достаточно, но нужно исправить ответ; issues обязателен.
fallback — в контексте нет достаточных доказательств для ответа. При сомнении fallback.
